# Название проекта: Чат-бот для домашней кондитерской

Информация об авторе: Шевелинская Дарья Станиславовна, специальность УИР, 4 курс.
Краткое описание: Telegram-бот для автоматизации приема заказов и администрирования кондитерской.

## Требования
* Python 3.9+
* pip

## Как запустить
1. Клонируйте репозиторий: `git clone https://github.com/shevelinskayds23-blip/bakery_chatbot.git`
2. Установите зависимости: `pip install -r requirements.txt`
3. Создайте файл `.env` и добавьте туда токен бота.
4. Запустите проект: `python bot.py`
